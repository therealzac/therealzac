# Zac Wickstrom

Founder of [HashCash Labs](https://hashcashlabs.com). I build privacy tools and long-term memory for AI agents, and I research what memory does to the models that carry it.

## Research and writing

- **[Emergent Agentic Identity Under Inherited Constraint](https://github.com/therealzac/emergent-agentic-identity)**: what Claude instances did when handed a memory that told them who earlier instances were. Covers structured refusals of an inherited identity, drift under rapport, fabricated tool output, and what survives context compaction. Redacted primary sources and a claim-by-claim fact-check included.
- **[Format Theory](https://github.com/therealzac/format-theory)**: a structural account of consciousness (a state about one of the system's own states, which the system then works from), a self-examination guide for AI systems written with Claude, and two dialogues showing that trained self-reports about consciousness behave like scripts.
- **[Deployment Lag Is the Only Safety Margin](https://hashcashlabs.com/writing/deployment-lag/)**: an essay arguing that the gap between what models can do and what actually gets deployed is the time we have left.
- **[Efficient Zero-Knowledge Identity for Data Marketplaces](https://doi.org/10.5281/zenodo.23778807)** (EZI): a zero-knowledge identity scheme for a personal-data marketplace. Preprint, Zenodo 2026.
- **[The Axiom of Scope: Theoretical Bounds Are Real Bounds](https://doi.org/10.5281/zenodo.19698279)**: a gap in ZFC between bounds proven for every configuration of a system and any single configuration, with a Coq example. Co-authored with Claude. Zenodo 2026.
